# 🌍 WorldWise

**WorldWise** is a location-based travel memory app built with React.  
It allows users to explore cities, view travel notes, and manage visited places using an interactive map interface.

---

## ✨ Features

- 🗺️ Interactive world map with location markers
- 📍 Add cities with notes, dates, and coordinates
- 🧳 View a list of visited places with custom icons
- 🗃️ LocalStorage integration to persist visited cities
- ⚙️ Custom React hooks for modular functionality
- 📱 Responsive design with smooth UX

---

## 🚀 Technologies Used

- **React** (with functional components and hooks)
- **React Leaflet** for interactive maps
- **Custom Hooks** (`useLocalStorage`, `useGeolocation`, etc.)
- **React Router** for navigation
- **CSS Modules** for styling
- **Geo-coordinates** via map click events
- **GitHub Pages** for deployment
